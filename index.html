04 / 个人开源

开源项目。

parallel_query ↗

用于并行执行接口中的独立只读查询，通过 Future 获取结果并汇总返回。

  1. 01

    提交任务

    将用户、订单和账户等独立只读查询交给并行任务。

  2. 02

    同时查询

    使用 Java 21 虚拟线程，减少主流程中的串行等待。

  3. 03

    汇总返回

    通过 Future 取得各项结果，组合成接口响应。

JAVA
@ParallelScopepublic Profile load() {  var user = tasks.submit(this::loadUser);  var orders = tasks.submit(this::loadOrders);  var account = tasks.submit(this::loadAccount);  return new Profile(    tasks.await(user),    tasks.await(orders),    tasks.await(account));}
public Profile load() {  var user = loadUser();  var orders = loadOrders();  var account = loadAccount();  return new Profile(user, orders, account);}

准备提交三个查询

代码与动画同步。tasks 为注入的 ParallelQueryTasks；示例基于 1.1.0-SNAPSHOT 源码。动画时长不代表性能测试。
